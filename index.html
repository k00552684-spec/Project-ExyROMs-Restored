Deployment Protocol

// CLEAN FLASH (NEW INSTALL)
  1. Boot device into TWRP Recovery.
  2. Navigate: Wipe > Advanced Wipe.
  3. Format: Dalvik/ART, Cache, Metadata, Data.
  4. Install target ROM.zip package.
  5. (Optional) Inject GApps and Everline Kernel.
  6. Reboot system.
// DIRTY FLASH (UPDATE)
  1. Boot into TWRP Recovery.
  2. Wipe: Dalvik/ART Cache and Cache only.
  3. Install updated ROM.zip.
  4. (Optional) Reflash Custom Kernel.
  5. Reboot system.
