05 / FLASHING GUIDE

Make the switch.

Requires an unlocked bootloader and USB debugging enabled. Follow every step carefully for Samsung Exynos 9611 devices.

Connect your phone to your PC with USB debugging enabled and reboot directly into Samsung Download mode:

>_ TERMINAL
adb reboot download

Flash the recovery using Odin (place in AP slot with Auto Reboot OFF) or run Heimdall (include vbmeta_disabled.img if required by the build):

>_ TERMINAL
heimdall flash --RECOVERY recovery.img --VBMETA vbmeta_disabled.img --no-reboot

Exit Download mode by holding Vol Down + Power. The exact moment the screen goes black, immediately switch to holding Vol Up + Power to boot into custom recovery. Note: A normal boot into stock OS can overwrite custom recovery with stock recovery.

Select Format Data (type yes) inside recovery, start ADB Sideload from the recovery menu, and flash the ROM package (plus GApps if not bundled):

>_ TERMINAL
adb sideload rom.zip # If GApps aren't bundled with the ROM: adb sideload gapps.zip

Once complete, select Reboot System from the recovery menu.

Before you flash

Make a full backup of your internal storage. Formatting data is mandatory on clean installs and will erase all user files.
