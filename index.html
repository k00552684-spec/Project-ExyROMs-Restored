05 // DOCUMENTATION & RECOVERY INSTALL

Make the switch.

Requires an unlocked bootloader and USB debugging enabled. Follow the exact Samsung Odin/Heimdall sequence.

Connect your Exynos 9611 device via USB with ADB debugging authorized and reboot into Samsung Download mode:

>_ TERMINAL
adb reboot download

Flash recovery via Odin (AP slot, untick Auto Reboot) or run Heimdall with disabled VBMeta verification:

>_ TERMINAL
heimdall flash --RECOVERY recovery.img --VBMETA vbmeta_disabled.img --no-reboot

Exit Download mode by holding Vol Down + Power. The exact moment the screen goes black, immediately switch to Vol Up + Power until TWRP/OrangeFox loads. Allowing a normal boot will restore stock recovery.

Format Data (type yes) in recovery, enable ADB Sideload, and flash the ROM zip (plus GApps if using a Vanilla build):

>_ TERMINAL
adb sideload rom.zip adb sideload gapps.zip reboot system
Before you flash: Make a full backup. Formatting data is mandatory on clean installs and will erase internal storage.
