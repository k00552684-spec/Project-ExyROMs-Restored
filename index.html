05 // DOCUMENTATION & RECOVERY INSTALL

Make the switch.

Requires an unlocked bootloader and USB debugging enabled. Follow the exact Samsung Odin/Heimdall sequence.

>_ TERMINAL adb reboot download
>_ TERMINAL heimdall flash --RECOVERY recovery.img --VBMETA vbmeta_disabled.img --no-reboot
Hold Vol Down + Power to exit Download mode. The instant the screen goes black, immediately switch to Vol Up + Power to boot into custom recovery.
>_ TERMINAL adb sideload rom.zip adb sideload gapps.zip reboot system
Before you flash: Make a full backup. Formatting data is mandatory on clean installs and will erase internal storage.
